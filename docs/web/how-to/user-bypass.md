# How-To: User & Group Bypass (Split Tunneling)

TTP supports selective cleartext network access for specific system users or groups using `--bypass-user` and `--bypass-group`.

---

## 1. Exempting a Specific User

To run a specific local user outside the Tor transparent proxy:

```bash
sudo ttp start --bypass-user clearnet-user
```

Any process owned by `clearnet-user` will bypass `nftables` redirection and connect directly to the WAN.

---

## 2. Exempting a Group

To exempt all processes belonging to a specific group:

```bash
sudo ttp start --bypass-group devgroup
```

---

## 3. Running One-Off Commands via `ttp run`

If you want to execute a single command as a bypassed user without switching accounts manually:

```bash
sudo ttp run --user clearnet-user -- wget https://example.com
```

---

## Security Considerations

!!! warning "Cleartext Exposure"
    Traffic generated by bypassed UIDs/GIDs does **not** go through Tor. Do not run applications carrying sensitive personal identifiers under a bypassed identity while relying on Tor for anonymity.
